КИРИЛЛ FIT — как выложить и установить

Это обычный веб-сайт: 11 файлов и 3 папки с фото (img1, img2, img3). Он не связан с Claude, ChatGPT или
любым другим сервисом ИИ. После первого открытия работает и без интернета.
Подходит для iPhone с iOS 13 и новее (iPhone 6s и новее), открывать в Safari.

ШАГ 1. ВЫЛОЖИТЬ В ИНТЕРНЕТ (бесплатно, один раз)
Вариант А — Netlify (быстрее всего, около 3 минут):
  1. На компьютере откройте app.netlify.com/drop и зарегистрируйтесь бесплатно.
  2. Перетащите в окно папку kirill-fit целиком.
  3. Получите адрес вида https://что-то.netlify.app — это ссылка на приложение.
     В настройках сайта (Site configuration → Change site name) можно задать
     понятное имя, например kirill-fit-2026.
Вариант Б — GitHub Pages:
  1. Зарегистрируйтесь на github.com и включите двухфакторную защиту.
  2. New repository → имя kirill-fit → Public → Create.
  3. «uploading an existing file» → перетащите все файлы из папки → Commit.
  4. Settings → Pages → Branch: main → Save. Через 1–2 минуты появится адрес
     https://ваш-логин.github.io/kirill-fit/

ШАГ 2. ПРОВЕРИТЬ НА СВОЁМ iPHONE
  1. Откройте ссылку в Safari.
  2. «Поделиться» (квадрат со стрелкой) → «На экран „Домой“» → «Добавить».
  3. Откройте с иконки, пройдите настройку, проведите тестовую тренировку.
  4. Включите авиарежим и откройте снова — всё должно работать.
  5. Перед подарком: «Ещё» → «Удалить все данные» (или удалите иконку).

ШАГ 3. ПОДАРИТЬ
  Отправьте Кириллу ссылку в сообщении или распечатайте QR-код на открытке.
  Дальше он делает пункт 2 из шага 2.

ОБНОВЛЕНИЕ
  Netlify: Deploys → перетащите новую папку.
  GitHub: Add file → Upload files. За раз можно загрузить не больше 100 файлов,
  поэтому папки img1, img2, img3 загружайте по одной, а потом остальные файлы.
  В файле sw.js увеличьте номер VERSION. У Кирилла обновится при следующем
  открытии с интернетом. Его данные при обновлении не теряются.

ВАЖНО
  Данные хранятся только на iPhone. Раз в неделю: «Ещё» → «Сохранить
  резервную копию» → в «Файлы»/iCloud Drive. Если удалить иконку приложения,
  данные удалятся вместе с ней.
